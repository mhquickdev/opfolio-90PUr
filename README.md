## 🚀 How to Run Locally

1. **Unzip** the project files.
2. **Install Dependencies**:
   ```bash
   composer install
   npm install
   ```
3. **Setup Environment**:
   ```bash
   cp .env.example .env
   php artisan key:generate
   ```
4. **Run Dev Server**:
   ```bash
   php artisan serve
   npm run dev
   ```
